# Ключ и замок

Учебник-практикум по защите информации к дисциплине «Криптографические методы защиты информации». Esil University,
направление ИС. Автор — Малика Ерболқызы, 2026.

Замысел: каждый раздел учит с нуля — сначала просто, потом глубже, до уровня вуза. Студенту — объяснения, модели и
самопроверка; преподавателю — индивидуальные варианты, автопроверка и материалы к занятию.

## Что готово

Проект в работе. Сейчас готов флагманский раздел в консольной версии 1 — практикум **«Wi-Fi под защитой: от WEP к
WPA3»** (папка `python/`): справочник протоколов с источниками, четыре принципа безопасного протокола с расчётными
заданиями, аудитор настроек точки доступа, индивидуальные варианты и автопроверка бланков. Нужен Python 3.10+, только
стандартная библиотека; запуск и команды — в [`python/README.md`](python/README.md).

Следующий шаг — веб-версия, которая открывается в браузере на компьютере, телефоне и планшете без установки.

## Устройство

```
data/        общие данные: протоколы, принципы, правила аудитора, источники
docs/lab/    лабораторная работа «Защита беспроводных сетей: от WEP к WPA3» (.md и .docx)
python/      консольная версия 1: программа, команды преподавателя, демо-банк вопросов, тесты
```

## Рамки

- Проект учит защищать. Программа не работает с сетью, не сканирует эфир, не подключается к сетям Wi-Fi и не
  спрашивает настоящих паролей, имён сетей, IP- и MAC-адресов.
- Секрет преподавателя, ключи ответов и закрытый банк вопросов с ответами в репозиторий не входят: преподаватель
  получает их лично. Здесь — демо-банк для тестов и пробы.
- У каждого факта есть источник (`data/sources.json`); что не удалось сверить, помечено «[проверить]».
