# Clavis

Учебник-практикум по защите информации к дисциплине «Криптографические методы защиты информации». Esil University,
направление ИС. Автор — Малика Ерболқызы, 2026.

Замысел: каждый раздел учит с нуля — сначала просто, потом глубже, до уровня вуза. Студенту — объяснения, модели и
самопроверка; преподавателю — индивидуальные варианты, автопроверка и материалы к занятию.

*Clavis* — по-латыни «ключ». В 1606 году под названием «Clavis Steganographiae» вместе со «Стеганографией» Иоганна
Тритемия напечатали книжку, объяснявшую, как устроены шифры двух первых её книг (Reeds J. Solved: The Ciphers in
Book III of Trithemius's Steganographia // Cryptologia. 1998. Vol. 22, no. 4); «Clavis Polygraphiae» завершает и его
«Полиграфию» 1518 года ([запись Библиотеки Конгресса](https://www.loc.gov/item/32017914)). Ключ и замок остались в
знаке учебника.

## Что готово

Проект в работе.

**Консольная версия 1** — практикум **«Wi-Fi под защитой: от WEP к WPA3»** (папка `python/`): справочник протоколов
с источниками, четыре принципа безопасного протокола с расчётными заданиями, аудитор настроек точки доступа,
индивидуальные варианты и автопроверка бланков. Нужен Python 3.10+, только стандартная библиотека; запуск и команды —
в [`python/README.md`](python/README.md).

**Веб-версия, каркас** (`index.html`) — открывается в браузере на компьютере, телефоне и планшете, без установки и
без интернета:

- вход для студента и для преподавателя (материалы к паре по разделам); кабинет преподавателя и режим проектора
  пока помечены «скоро»;
- карта из 16 разделов; раздел 11 «Беспроводные сети» — первый: ступени «Просто», «Попробуй», «Проверь себя»
  (8 вопросов), «Дома» (памятка по домашнему роутеру и сортировка советов лекции 14–15) и «Преподавателю»
  (сценарий «миссия на паре» на 20 минут, лабораторная из `docs/lab/`, QR-код для телефонов); модели «Кто примет
  твоё сообщение?» и «Повтор одноразовых значений», вопросы с разбором каждого варианта и лестницей подсказок;
  раздел 13 «Право и этика» — ступени «Просто», «Попробуй», «Проверь себя» и сортировка случаев по корзинам;
- карта к экзамену (`index.html#ekzamen`): 117 контрольных вопросов из лекций курса, пересказанных своими словами,
  и место в учебнике, где разобран каждый; счётчик «разобрано N из 117» считается сам по отметкам в текстах;
- миссия «Повтор одноразового числа» в вымышленном мире «Бюро „Кілт“»: журнал эфира, гамма (первое слово секрета
  игрок дочитывает сам), предписание с проверкой правил на сутках эфира, загадка, заключение с историей настоящего
  Wi-Fi, карточки и награды;
- языки интерфейса: русский; казахский и английский — черновой перевод с пометкой «не проверено носителем».
  Тексты разделов и миссии пока только на русском;
- светлая и тёмная тема, режим «Группой» для занятия у общего экрана (крупный текст и буквы у вариантов);
- страница «Модель содержания» (`index.html#model`) — для автора текстов: проверка всех файлов и подсказки, что
  исправить.

## Как открыть

**Из папки.** Дважды щёлкнуть `index.html` — страница откроется в браузере прямо из папки (`file://`), сервер не
нужен.

**С сайта.** После первого открытия учебник сохраняет свою копию на устройстве и дальше открывается без интернета;
блок «Учебник на этом устройстве» на входе показывает, готова ли копия, и помогает установить учебник как
приложение — значком на экран телефона или компьютера. Новая версия скачивается сама и включается при следующем
открытии. Копию ведёт `sw.js` по списку файлов с отпечатками SHA-256: файл, который не совпал с отпечатком, на
устройство не попадёт.

Прогресс, ответы и коллекция карточек хранятся только в этом браузере, без имени; у этих данных есть номер версии
(`js/store.js`), а всё испорченное или незнакомое при чтении отбрасывается.

Тексты учебника — обычные текстовые файлы в папке `content/`; как их править без программирования —
[`content/README.md`](content/README.md). Два правила оттуда стоит знать заранее:

- **Коды постоянные.** У раздела, ступени, вопроса, миссии и карточки есть короткий код латиницей (`r11`, `prosto`,
  `r11-01`, `r11-m01`, `nonce`). По кодам страница находит тексты и хранит прогресс, поэтому названия, номера и
  порядок разделов менять можно, а выданный код — нельзя. Повтор кода и вопрос с кодом чужого раздела проверка не
  пропустит.
- **В тексте нельзя писать подряд знаки `$` и `{` и ставить обратную кавычку.** Файл содержания — это текст в
  обёртке JavaScript: обратная кавычка обрывает его, а то, что стоит в `${…}`, браузер выполнил бы как код. Оба
  запрета проверяет тест `tests/content.test.js` по исходному тексту файлов.

## Как проверить

Из корня репозитория. Тесты веб-версии (нужен Node.js, проверено на версии 24; пакеты ставить не нужно):

```
node --test models/tests/frame.test.js models/tests/nonce-reuse.test.js tests/content.test.js tests/exam.test.js tests/mission.test.js tests/offline.test.js tests/qr.test.js tests/web-frame.test.js
```

Тесты консольной версии и данных (из папки `python/`):

```
py -3 -X utf8 -m unittest discover -s tests
```

Ожидаемый результат: веб-версия — 84 теста, все пройдены (`pass 84`, `fail 0`); консольная — `Ran 216 tests … OK`.

Копия источников для страницы (`data/sources.js`) и эталонные числа модели (`tests/vectors/nonce-reuse.json`)
делаются из общих данных скриптами `py -3 tools/web_data.py` и `py -3 tools/make_vectors.py`; с ключом `--check`
первый скрипт только сверяет копию с `data/sources.json`.

**После любой правки файлов учебника** (тексты, код, оформление, значки) — `node tools/offline.js`: команда заново
собирает список файлов и их отпечатки в `sw.js`. Без неё сайт продолжит раздавать устройствам прежнюю копию, а тест
`tests/offline.test.js` скажет, какой файл разошёлся со списком.

## Устройство

```
index.html   веб-версия: одна страница, разделы открываются по адресу после # (#karta, #r11-prosto, #missiya-r11-m01)
sw.js        копия учебника на устройстве: работа без интернета (список файлов вписывает tools/offline.js)
manifest.webmanifest, icons/   установка как приложения: название, цвета, значки для светлой и тёмной темы
css/         оформление: base.css — учебник, mission.css — миссии
js/          код страницы: разметка текстов, модель содержания, интерфейс, интерактивы, миссии, QR-код (qr.js —
             переложение библиотеки Project Nayuki, лицензия MIT — в начале файла)
models/      модели миссий (nonce-reuse.js — повтор одноразового числа) и их тесты
content/     тексты учебника: карта разделов, ступени, строки интерфейса, миссии
fonts/       шрифты Lora, PT Sans, PT Mono и их лицензии (SIL Open Font License)
tests/       тесты веб-версии, эталонные числа модели и эталонные QR-коды
tools/       скрипты: копия источников для страницы, эталонные числа, список файлов для работы без интернета
data/        общие данные: протоколы, принципы, правила аудитора, источники
docs/lab/    лабораторная работа «Защита беспроводных сетей: от WEP к WPA3» (.md и .docx)
python/      консольная версия 1: программа, команды преподавателя, демо-банк вопросов, тесты
```

## Рамки

- Проект учит защищать. Программа не сканирует эфир, не подключается к сетям Wi-Fi, не работает с трафиком и не
  подбирает пароли; не спрашивает настоящих паролей, имён сетей, IP- и MAC-адресов.
- Миссии — игровые модели известных и давно исправленных ошибок на учебном полигоне: игрушечный алфавит, короткие
  выдуманные сообщения, ни сети, ни инструментов, ни форматов настоящих пакетов. Мир миссии назван вымышленным.
- Веб-версия не обращается к чужим адресам и ничего никуда не отправляет: всё — шрифты, тексты, модели — лежит в
  проекте, а с сайта она берёт только собственные файлы. Политика безопасности
  страницы (CSP) запрещает загрузку чужого кода и вставку HTML-строк; это проверяют тесты `tests/web-frame.test.js`.
- Секрет преподавателя, ключи ответов и закрытый банк вопросов с ответами в репозиторий не входят: преподаватель
  получает их лично. Здесь — демо-банк для тестов и пробы; вопросы «Проверь себя» — открытая тренировка.
- У каждого факта есть источник (`data/sources.json`); что не удалось сверить, помечено «[проверить]». Аналогия
  всегда названа аналогией.
